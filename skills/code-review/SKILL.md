# Code Review 技能

审查本项目代码时，按以下步骤执行：

1. 用 read_file 完整读取目标文件（必要时用 glob 找相关文件）。
2. 依次检查这些方面，每发现一条记录一条：
   - **工具函数是否都返回字符串**（本项目 DeepSeek 兼容接口的硬性要求，返回数字会报 400）
   - 是否有裸 `except:`（应捕获具体异常，至少 `except Exception`）
   - 文件工具是否都经过 `_safe_path`（路径必须限制在项目目录内）
   - 是否有硬编码的 API 密钥或敏感信息
   - 是否有明显 bug：变量名错误、逻辑写反、参数顺序错误等
   - 注释和文档是否与代码实际行为一致
3. 输出格式：
   - 问题清单：每行一条，格式为 `文件:行号 - 问题描述 - 修改建议`
   - 没有问题就明确写「未发现问题」。
